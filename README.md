# Weather App

A modern React.js weather application with real-time weather updates and forecast data.

## Features

- Current weather data
- 5-day weather forecast
- Current location weather
- Dynamic weather backgrounds
- Responsive design
- Loading animations
- Local storage support

## Technologies Used

- React.js
- Vite
- OpenWeather API
- CSS
